# 3a단계 작업 컨텍스트 — 둘다좋아

## 지금 단계: 3a단계 — 둘다좋아 (데이트 후보 결정)

## 기능 설명
각자 몰래 데이트 후보를 고르고, 양쪽이 같은 걸 선택하면 결과 공개.
"오늘 뭐 할까?" 결정을 게임처럼 만드는 기능.

## 목표
- [ ] features/date-decision/ 폴더 구조 생성
- [ ] 데이트 후보 목록 화면 (제목, 카테고리, 장소)
- [ ] 후보 추가/삭제 기능
- [ ] 각자 몰래 투표 UI (내 선택은 보이고, 상대 선택은 ? 처리)
- [ ] Firestore dateCandidates 컬렉션 연동 (coupleId 기준)
  - votedBy[] 배열로 투표 여부 체크
  - 상대방이 투표했는지 여부만 보여줌 (어떤 후보인지는 비공개)
- [ ] 양쪽 모두 투표 완료 시 자동 결과 공개 화면
- [ ] 매칭 성공 시 (같은 후보 선택) → 축하 화면
- [ ] 매칭 실패 시 (다른 후보 선택) → 결과 표시 후 재투표 유도
- [ ] 투표 완료 후 후보 초기화 or 보관 처리
- [ ] feature-registry/registry.ts에 등록 (status: 'experimental')
- [ ] **Jest 단위 테스트**: `castVote.test.ts`(트랜잭션 reveal 전이), `startNewRound.test.ts`(라운드 종료/시작), `removeCandidate.test.ts`(진행 중 라운드 처리)

## 완료 기준
- 후보 추가 후 양쪽 각자 선택 → 결과가 동시에 공개됨
- 상대방이 투표 완료 전까지 상대 선택 내용이 보이지 않음
- 매칭 여부와 관계없이 결과 화면이 정상 표시됨
- 실험실 탭에서 ON/OFF 토글 작동
- **vote.md 의 BR ↔ 테스트 매핑** 모두 매핑됨, 단위 테스트 green
