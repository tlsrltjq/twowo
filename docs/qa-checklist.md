# 수동 QA 체크리스트 (E2E)

> **언제 사용**: stage-7 진입 시 1회, TestFlight 빌드 후 1회.
> **누가**: 사람(두 명) 또는 시뮬레이터 2개.
> **목적**: 자동화하기 어려운 시나리오(권한 다이얼로그, 푸시 알림, 실기기 동작, 디자인 일관성)를 한 번에 점검.
>
> 진행은 두 기기를 **A** / **B** 로 부른다. 각 시나리오는 *완료 = 양쪽 다 의도대로 동작* 일 때만 체크.

## 0. 사전 준비
- [ ] 두 기기에 production 또는 preview 빌드 설치
- [ ] 두 기기 모두 Wi-Fi 또는 LTE
- [ ] 둘 다 시간 자동 동기화 (KST 보장)
- [ ] 두 Apple ID 또는 Google 계정 준비
- [ ] Firebase 콘솔 열어두기 (실시간 데이터 확인용)

## 1. 인증 + 커플 연결 (1단계 — auth-couple)
- [ ] A: 회원가입(이메일) → users 문서 생성, coupleId=null
- [ ] A: 커플 연결 화면 → 코드 생성 → 6자리 영숫자 표시
- [ ] B: 회원가입(구글) → 코드 입력 → 연결 완료 → 메인 진입
- [ ] B 시점에 A 화면도 자동으로 메인 진입 (실시간 감지)
- [ ] **잘못된 코드**: 임의 6자리 입력 → "잘못된 코드" 안내
- [ ] **본인 코드 본인 입력**: 거부 메시지
- [ ] **만료 시뮬**: Firebase 콘솔에서 invitations.expiresAt 을 과거로 → 입력 시 "만료" 안내
- [ ] **권한 검증**: B 가 비로그인 상태로 임의 coupleId 의 데이터를 가져오려고 하면 PERMISSION_DENIED

## 2. 캘린더 + 사진 (2단계 — calendar)
- [ ] A: 일정/운동/데이트 각 1개씩 추가 → B 에 실시간 표시
- [ ] B: 같은 이벤트 수정 → A 에 즉시 반영
- [ ] A: 이벤트에 사진 라이브러리에서 3장 첨부 → 썸네일 1초 이내 표시
- [ ] **카메라 권한 1차 거부 → 다시 시도** 시 안내 카드 + "설정 앱 열기" 동작
- [ ] **카메라 촬영** 으로 1장 추가 → 사진 뷰 그리드 갱신
- [ ] 뷰 전환 (캘린더/사진/운동/데이트) → 깜빡임/로딩 X
- [ ] 운동 뷰에서 이번 달 합계 시간 표시
- [ ] 이벤트 삭제 → Firebase 콘솔에서 photos 메타 + Storage 객체 모두 사라짐 (BR-8)
- [ ] **오프라인**: 비행기 모드 ON → 이벤트 추가 → 캐시 저장 → 비행기 모드 OFF → 자동 동기화

## 3a. 둘다좋아 (vote)
- [ ] A,B 둘 다 후보 추가 → 양쪽 목록 동일
- [ ] A 만 투표 → B 화면에 상대 선택 비공개
- [ ] B 도 투표 → 즉시 결과 공개 (매칭 성공/실패 분기)
- [ ] 매칭 성공 → "캘린더에 추가" → general 이벤트 생성됨
- [ ] 새 라운드 시작 → 후보 유지

## 3b. 컨디션 (mood)
- [ ] A 입력 → B 홈 카드 1초 내 갱신
- [ ] **23:59 KST 직전 수정** → 가능
- [ ] **자정 직후 수정 시도** → MoodLockedError (UI에서 차단)
- [ ] 다른 날 데이터 수정 시도 → UI 가 비활성
- [ ] 7일 히스토리 표시

## 3c. 빙고 (bingo)
- [ ] A: 25개 항목 채우기 → 새 빙고판 시작
- [ ] A,B 동시 셀 체크 → 둘 다 반영, checkedBy 갱신
- [ ] **라인 완성** → 본인 햅틱 + 축하 + Lottie 재생 1회
- [ ] B 화면에도 즉시 체크 반영
- [ ] 25칸 완성 → 빙고판 completed
- [ ] 새 판 시작 가능

## 4. 홈 화면 + 알림 (home)
- [ ] 홈 카드: 양쪽 컨디션 / 다가오는 일정(3개) / 투표 배너 / 빙고 진행률
- [ ] 디데이 표시 (KST 기준)
- [ ] **알림 권한 거부** 상태에서 앱 크래시 X, 권한 안내 배너 한 번만 노출
- [ ] **알림 권한 허용** → Firestore users.expoPushToken 저장
- [ ] **로컬 알림**: 오후 8시 KST 전 본인 컨디션 미입력 → 알림 수신
- [ ] **원격 알림**: A 컨디션 입력 → B 기기 푸시 수신 (실기기 필요)
- [ ] 자기 자신에게는 푸시 안 옴 (BR-7)

## 5. 실험실 (lab)
- [ ] experimental 기능 목록만 표시
- [ ] A: 토글 OFF → B 화면에서도 그 기능 탭 사라짐
- [ ] A: 토글 ON → 양쪽 탭 노출, 데이터 그대로
- [ ] 동시 토글 (양쪽이 같은 시각에 반대 방향) → last-write-wins, 토스트 안내

## 6. 설정 + 커플 해제 (settings)
- [ ] A: 닉네임 변경 → B 화면 실시간 갱신
- [ ] 로그아웃 → 로그인 화면, AsyncStorage uid 비워짐
- [ ] **커플 해제** 2단계 확인 → 양쪽 자동 "재연결 대기" 화면
- [ ] 재연결 대기 화면에 남은 일수 표시 ("30일 후 ...")
- [ ] **재연결**: 양쪽 동의 → 메인 화면 복귀, 모든 데이터 보존
- [ ] **완전 삭제**: "지금 영구 삭제" → Firestore 컬렉션 + Storage 폴더 비어짐
- [ ] **Scheduled Function 수동 트리거** (개발 단계만): disconnectedAt 을 31일 전으로 → 함수 실행 → 같은 결과

## 7. 디자인 일관성 (design-system)
- [ ] 모든 화면 색상이 토큰 외 값 없음 (눈으로 비교)
- [ ] 폰트 Pretendard 4종 모두 로드 (개발자 도구 또는 시각 점검)
- [ ] 4pt 그리드 일관성 (간격이 4의 배수)
- [ ] 라이트 모드만 (다크모드 ON 해도 라이트 톤 유지)
- [ ] 빈 상태 / 에러 상태 / 로딩 상태 모두 처리되어 있음
- [ ] 햅틱: 버튼/토글 탭, 매칭 성공, 빙고 완성 시 진동 발생

## 8. 접근성 (a11y)
- [ ] iOS VoiceOver ON → 모든 버튼이 의미 있는 라벨로 읽힘
- [ ] 시스템 글자 크기 "특대" → 레이아웃 깨짐 없음
- [ ] 색맹 모드 (회색조) → 이벤트 타입 점 구분 가능 (위치/아이콘으로도 구분)
