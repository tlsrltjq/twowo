# _archive — 보관용 (진실 소스 아님)

여기 있는 파일은 **참고/이력 보관용**입니다. 진행/규칙의 진실 소스는 루트 `CLAUDE.md`,
`HARNESS.md`, `tasks/`, `docs/specs/`, 보안 규칙 파일입니다.

## 아카이브된 파일

### 디테일 참고 문서 (룰북으로 대체됨)
- `frontend.md` — 프론트엔드 패턴/코드 디테일. 룰북: `FRONTEND_RULES.md`
- `testing.md` — 테스트 패턴/에뮬레이터 디테일. 룰북: `TEST_STRATEGY.md`
- `design-system.md` — 디자인 토큰/컴포넌트 디테일. 토큰 SSOT: `design-system/tokens.ts`
- `dev-environment.md` — TS 설정/EAS/앱 메타 디테일. SSOT: `eas.json`, `tsconfig.json`
- `qa-checklist.md` — 수동 E2E 체크리스트. 7단계 TestFlight 직전에 사용.
- `wireframes/app-wireframe-board.html` — 초기 와이어프레임 보드. 현재는 `docs/specs/*.md` 의 ASCII 와이어프레임이 SSOT.

### 기획 원본
- `커플앱_프로젝트_계획서.docx` — 최초 기획 원본 (내용은 docs/* 와 specs/* 로 이관됨)
- `Claude_Code_하네스_자동화_가이드.docx` — 하네스 설계 원본 (CLAUDE.md/HARNESS.md 로 이관됨)

`*.docx` 는 `.gitignore` 로 버전 관리 제외.
